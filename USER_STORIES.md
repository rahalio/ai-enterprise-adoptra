# Adoptra — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### CDAO / Analytics transformation sponsor

- As a CDAO, I want each major use case plotted on Align–Act–Adjust–Adopt–Adapt with exit gates, so that we stop calling a tech launch a completed transformation.
- As a CDAO, I want sponsorship and experimentation culture scores visible by business unit, so that I can intervene where politics are blocking ROI.
- As a CDAO, I want adoption spend shown as a percentage of total program budget, so that I can defend the 10–15% investment the evidence requires.

### Analytics CoE lead

- As a CoE lead, I want pilot results captured with control-group comparison, so that Act learnings fund Adjust rather than vanity demos.
- As a CoE lead, I want to brand and package insights for frontline consumption, so that branch or store managers stop treating analytics as a black box.
- As a CoE lead, I want operating-model changes (champion roles, SLAs, intake) versioned after each Adjust, so that scale does not reintroduce the pilot’s failure modes.

### Frontline manager (branch / store)

- As a branch manager, I want each lead or intervention to include a plain-language rationale, so that I can act with relationship-plus-insights confidence.
- As a store manager, I want my performance goals to reflect outcomes of insight-qualified actions, so that I am not measured on arbitrary call or meeting counts.
- As a frontline manager, I want to flag insights I do not trust, so that distrust becomes a managed Adjust item instead of silent non-adoption.

### Change lead / design facilitator

- As a change lead, I want 30-day challenges and contests instrumented against target behaviors, so that Adopt creates visible momentum.
- As a change lead, I want a train-the-trainer completion map by role, so that we do not scale processes managers cannot coach.

### Platform administrator / PMO

- As a transformation PMO, I want an audit trail of decision-right changes and sponsor assignments, so that board reporting is evidence-based.
- As an administrator, I want to freeze an initiative at Act when uptake is single-digit post-launch, so that we cannot “Adopt” failure.
- As a compliance reviewer, I want decision-rights history for regulated customer actions, so that insight-driven sales remain explainable.
